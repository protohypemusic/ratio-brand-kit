# Ratio Accounting brand kit

This folder holds Ratio Accounting's brand guide. For anything you make in or
from this folder that carries the Ratio name or goes to a client (documents,
PDFs, spreadsheets, slides, emails, charts), read `ratio-brand/SKILL.md` first
and follow it, along with `ratio-brand/reference/writing.md` and
`ratio-brand/reference/documents.md`.

Use the logo and font files in `ratio-brand/assets/` directly. Never retype or
redraw the logo.

Save new work in a `work/` folder (create it if needed), not inside
`ratio-brand/`.
